# Go Background Job Queue

## What it does
A background job processing system built with Go.

## Features
- Worker pool
- Priority queue
- PostgreSQL persistence
- Job retries
- Job cancellation
- Job recovery
- Job payloads
- Filtering and pagination
- Graceful shutdown

## Tech Stack
- Go
- PostgreSQL
- Docker
- REST API
